## Inputs

- `../05_publish/output/SIGNAL_[Month]_[Year].md`

## Process

1. Extract 3-5 social snippets from Debate and Trenches.
2. Write a LinkedIn post version (if applicable).
3. Write a Twitter/X thread version (if applicable).
4. Note any follow-up stories to track next month.
5. Record publication date and platform.
6. Update issue index if maintained.

## Outputs

- `output/social-snippets.md`
- `output/linkedin-post.md`
- `output/x-thread.md`
- `output/follow-up.md` — stories to watch next month.

## Review gate

No human gate required unless requested.
