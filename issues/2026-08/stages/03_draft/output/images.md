# Image prompts — SIGNAL Issue #6

## Architecture Debate: Source index vs build model

**Prompt:** Wide 16:9 diagram-comic matching the existing Scalac illustration
style. Warm off-white paper background, rough black marker outlines, solid black
sticky figures and red as the only accent. Split into two panels. Left: a developer
and a small bounded AI agent open a huge drawer labelled `SOURCE INDEX`; files and
symbols fly out along a red arrow labelled `22 SEC`. Right: the same pair wait
beside a tall machine labelled `BUILD MODEL`, which stamps `CLASSPATH`, `GENERATED
SOURCES` and `DIAGNOSTICS`. Between panels, a red warning says `FAST CAN BE
INCOMPLETE`. Top title: `WHAT SHOULD THE IDE BELIEVE FIRST?` Bottom line:
`NAVIGATE FAST. CHANGE ONLY AFTER THE BUILD AGREES.` No logos, gradients,
photorealism, dense UI or generic robots.

## Notes from the Trenches: Kafka holds the pressure

**Prompt:** Wide 16:9 diagram-comic in the same existing Scalac style. Warm
off-white background, thick black sketch lines, black sticky figures and red
accents only. Left to right, many tiny server boxes send red dashed event arrows
into a large cylinder labelled `KAFKA`. A calm engineer holds a red stop sign
before a slow box labelled `SERVICE MAP`; a red note above it says `MAP IS OLDER`.
Events queue visibly in Kafka and none fall into a bin. On the right, two engineers
read a clean map labelled `FRESHNESS: 4 MIN`. Top title: `WHEN STORAGE SLOWS, KEEP
THE EVENTS.` Bottom line: `STALE IS BETTER THAN MISSING.` A red looped arrow from
the slow box back to Kafka shows backpressure. No logos, gradients, dashboards or
generic AI robots.
