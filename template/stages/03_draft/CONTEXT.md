## Process

Write the first full draft of the newsletter:

1. Follow the section order from `newsletter-structure.md` exactly.
2. Use Today bullets from `today-bullets.md`.
3. Write the Debate and Trenches sections with bold hooks and linked evidence.
4. End Debate and Trenches with a concrete `Scalac angle`.
5. Write exactly 3 Signals: what changed + why it matters + migration path.
6. Write In the Know and Top Resources with direct links.
7. Apply The Code format from `voice.md`.
8. Do not polish here. Get structure, argument, and links right.
